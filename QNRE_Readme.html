👁️ 操盤手前言：
估值哲學與博弈對弈論

在進入任何量化運算之前，你必須先釐清「價值」與「價格」的真實定義。無數散戶在市場中賠錢，是因為他們盲信法人報告裡的「絕對合理價」，卻不知道對機構大人而言，估值定價本質上是一場「科學、文學與心理學」交織的自我實現預言。

本手冊的設計哲學，正是建立在以下「二元對立」的架構上：

⚖️ 上篇：估值哲學 ── 理解市場如何定價 企業價值與市場定價解耦

「企業的價值與股價，並不是同一件事。」

企業的獲利能力，可以透過營收、毛利率、費用率與產業趨勢推估，因此 EPS 的預測雖然仍有誤差，但主要建立在企業基本面的「客觀科學分析」上。然而，本益比（PE）代表的是市場願意為同一份獲利支付多少價格，其本質反映的是市場情緒、風險偏好、資金環境與未來預期，因此具有高度的主觀性。

相較於 EPS，PE 並不存在唯一正確的答案。相同的企業，在不同的景氣循環、利率環境與市場情緒下，都可能獲得截然不同的估值。

🎯 核心分離思維：

因此，本系統將市場因素主要納入 PE，而非頻繁調整 EPS。我們希望將「企業價值」與「市場定價」分開思考：

  • ✔ 讓 EPS 專注反映企業最純粹的獲利能力，不被短線喧囂輕易污染。
  • ✔ 讓 PE 反映市場對未來的定價，並將所有的市場情緒、籌碼擁擠度與大盤引力鎖在 PE 的乘數裡。

研究報告中的目標價，也應理解為一種估值觀點，而非絕對真實價值。分析師除了評估企業本身，也必須判斷市場願意接受什麼樣的估值，因此目標價往往會隨著市場共識、產業敘事與風險偏好持續修正。對投資人而言，與其將目標價視為終點，不如將其視為市場共識在不同時間點的具體呈現。

本系統並不追求一個永遠正確的「合理價」，而是建立一套能同時描述企業基本面與市場估值變化的「動態坐標系」。

⚔️ 下篇：博弈實戰 ── 扒光法人的籌碼操縱術 小蝦米對抗大鯨魚

在理解了理性的架構後，你必須立刻換上冷酷的博弈面具。在實戰戰場上，你必須扒光法人的「國王新衣」，看穿本益比是如何成為他們操縱共識的魔術棒：

1️⃣ 本益比是法人的「配平數字」與估值橡皮筋

在財務模型裡，表面上公式是 EPS × PE = 目標價。但實務上，外資研究員寫報告時往往是倒過來算的：

  • • 先看著線型與熱度，決定一個想喊的目標價（如想喊 2,000 試風向）。
  • • 接著代入認真算出的預估 EPS（假設 100 元）。為了讓公式成立，就把 PE 填上 20 倍。
  • • 若隔天股價漲了，想把目標價提到 2,500，只需寫一句「鑑於 AI 綜效顯現，上調本益比至 25 倍」，數學就又通了。
本益比怎麼解釋都通，它只是一個用來合理化股價行為的橡皮筋。

2️⃣ 「凱因斯選美理論」：合不合理不重要，共識才重要

法人非常清楚，所謂的「絕對合理價」根本不存在。他們寫報告、喊目標價，本質上是一種「宣傳與共識凝聚」。

當一家大外資開第一槍調高目標價，其他外資為了績效不落後，就會跟進報告，這時「共識」就形成了。

一旦共識形成，資金就會瘋狂湧入，股價自然朝著目標價前進。這就是「自我實現預言」。

線是他們畫的，風向是他們帶的，他們只要當那個點火的人就好。

3️⃣ 「切香腸式」階梯喊價的收割秘密

為什麼法人不一次給出他們真正推估的合理價？因為法人手上的股票動輒幾千幾萬張，需要巨大的流動性才能安全進出。

如果最終目標是 3,000 元，他們會先出報告喊 1,800 元。當散戶跟風推到 1,750 元時，法人就在這高位階「一邊出貨、一邊反向測試買盤強度」。

如果市場瘋狂進場，就再出報告把目標上調到 2,400 元誘敵深入。

這種「切香腸式」喊價法，才能創造源源不絕的交易量，讓法人分批結帳。

MACD (趨勢跟隨)

主升與初跌波段判定

趨勢判斷：紅柱變長代表多頭加速，紅柱變短代表多頭動能減弱。日線背離：股價創新高但紅柱能量沒跟上，且中途有明顯回落，代表主力買盤力竭。

📉

RSI (動能轉折)

專抓極端價格轉折

強弱動能：數值偏高偏多，偏低偏空。背離買賣點：股價頻創新高，但指標強弱度卻往下掉，代表虛胖；股價創低但強弱度不跌反升，代表底氣浮現。

📊

KD (震盪與軋空)

盤整區間高頻操作

區間套利：指標低檔交叉買進，高檔交叉賣出。高檔鈍化保護：當個股極強、指標連三天居高不下時，代表強勢軋空，不可盲目看空放空。

📉 熊市強制降溫 (大盤防禦)： 當大盤加權指數跌破年線進入長空趨勢時，系統會自動將個股「未來做夢」的權重移轉至「歷史已實現獲利」，強制降低整體估值預期。

獲利與換機潮或國際大宗商品報價高度相關，在獲利高峰時系統防禦性給予中低本益比。

D 級 (防禦估值起點)
內需防禦 / 低增長高現金流

營收與獲利成長穩定偏低，市場定價主體完全以「高股息」與「資產清算價值」為主。

2

RTS 企業結構轉換評分 本質轉機

結構得分 = 40% 獲利穩定度 + 30% 營收轉型度 + 30% 週期脫鉤度
  • 獲利穩定度：綜合評估公司是否能持續獲利、少有衰退，以及歷史盈餘跳動的穩定性。
  • 營收轉型度：精算近期與長期的營收動能落差，找出具備爆發性轉機的公司。
  • 週期脫鉤度：檢視毛利率是否能跳脫景氣循環，實現結構性的獲利擴張。
  • 👑 越級跳升機制：當上述三項結構指標優異達標，系統會自動調升該公司的本益比評級（例如自動將 B 級升至 A 級，享有更高估值）。
3

情緒與行為溢價（綜合反身性） 市場人氣

情緒溢價 = 基礎人氣溢價 + 軋空動能 + 斷頭壓力扣減 + 法人連續買超
  • 基礎人氣溢價：
    依據市場資金聚焦的熱度給予估值溢價。
  • 潛在軋空動能：
    當券資比攀高且股價極為強勢時，空單將被視為潛在軋空的火箭柴火。
  • 斷頭多殺多壓力：
    當融資暴增但股價卻跌破重要均線時，視為潛在多殺多賣壓，將扣減估值。
  • 法人大戶連買：
    追蹤外資與投信連續買超的天數，直接轉換為大戶背書的安全溢價。
4

大盤過熱 MCF 壓制與均線解封機制 安全限制

  • • 平滑解封權重：根據股價與季線、月線的相對位置，判定當前個股趨勢強弱，來控制上述「情緒溢價」能發揮的極限，避免弱勢股亂漲。
  • • MCF 崩盤防護：當大盤加權指數嚴重過熱、偏離年線過大時，系統會強制壓縮所有個股的本益比天花板，形成防護避震網，避免在泡沫頂端給出不切實際的目標價。

🏢 資產錨 (清算帳面底線)

資產錨 = 每股淨值 × 合理中軌本淨比倍數

在市場完全失去夢想與溢價預期時，提供淨值清算帳面的鐵底支撐。

💰 股息錨 (滾動股息支撐)

股息錨 = 近一年股息總和 ÷ 長線要求報酬率

要求報酬率涵蓋了無風險利率與產業風險溢酬。代表股價跌到何處時，會吸引防禦型存股資金進場接盤。

💡 成長股「零股息豁免」條款： 若公司因將現金投入結構成長而完全不配息（如高階科技/AI股），系統強制 100% 採用「資產錨」進行定價，豁免因零股息導致保底估值被公式腰斬的陷阱。
板塊加權定價比例：
  • 金融股：70% 股息錨 + 30% 資產錨
  • 傳產股：70% 資產錨 + 30% 股息錨
  • 科技/代工股：50% 資產錨 + 50% 股息錨
* 最終保底底價 = 板塊加權價 × 流動性折價因子 × (1 + 集團作帳溢價)

💡「預估年化 EPS × 最終本益比，投射出兼顧短期情緒與長期質變的時間定價矩陣。」

時間維度 主導因素 核心邏輯與防禦機制
短期 (1~3個月) 情緒與流動性 以中期 PE 疊加情緒反身性乘數。若遭遇短線高風險（當沖投機度超載、融資失守、且無攻擊型負數豁免），短期本益比強制打折壓制。
中期 (3~6個月) 預估 EPS + 大盤壓制 機構法人定價的核心錨點。以預估 EPS × 本益比計算，並受大盤 MCF 崩盤防護上限與保底防線制約。
長期 (6~12個月) 基本面結構定價 完全回歸 RTS 結構計量得分，不受短線市場泡沫情緒與資金流動干擾，尋找企業的長期真實價值。

💡「逆向推算當前股價究竟隱含了多龐大的市場夢想。以下提供 MEVM 折現預期曲線原理與機構操盤手判讀守則。」

🔮 逆向預期測謊核心

傳統估值是利用 預估EPS × 預估PE = 目標股價。這極易讓人陷入「無腦看好未來高成長」的敘事陷阱。
MEVM 是將「目前股價」逆向折算：
目前股價 ÷ 常態本益比 = 市場隱含目標 EPS

它直接解碼：當下買進這檔股票，代表你預設它在多少季內「完美不犯錯」地達標目標盈餘？

📈 操盤手核心判讀與預警指標

1. 市場隱含目標 EPS

目前股價反推後，企業必須實現的未來盈餘。若此數值遠高於目前實績，代表股價充斥高溢價本夢比。

2. 達標所需季數

企業需要維持當前成長率多少季才能安全達標。 • 4-8 季：常態合理區 • >12 季：嚴重透支未來

3. 實現機率衰減

預測時間越長，完美達標的勝率呈指數衰減。 • 勝率 <30%：隨時面臨殺估值雪崩

4. 營收初速校正

若個股短期營收動能強勁，系統會自動給予校正增益，減緩未來實現勝率的衰減速度。

⚔️ 機構操盤手：MEVM 實戰與逆向操盤三大金律

金律一：看清隱含夢想，防守泡沫 (測謊)

當市場群情激憤、利多頻傳，股價亮起高溢價紅燈時，請看「達標所需季數」。若隱含目標需要公司在未來 3 年內不犯任何錯地高速成長，且勝率衰減降至 30% 以下，代表預期極度透支，隨時面臨殺本益比的估值雪崩，嚴禁在此位階盲目重倉追高。

金律二：打破衰退預期，逆向建倉 (錯殺)

當好公司遭遇景氣逆風或大盤恐慌性大跌，定價狀態會被打入「價值錯殺」。此時市場預設下季必須繳出極端悲觀的衰退成績，只要你稽核其產業基本面並未死透，這種悲觀預期一旦被實績打破，就是絕佳的黃金錯殺買點。

金律三：景氣天峰防禦，防範循環陷阱

景氣循環股（如記憶體、航運、鋼鐵）在景氣天峰時，獲利極高導致靜態本益比極低、看似非常安全。但此時極可能就是最後的逃頂訊號，應搭配短線雷達死抱高檔鈍化，並在激情退去前果斷獲利了結。

📈 右側個股交易配置

依據當前個股股價與系統合理價的差距，動態引導配置：

1. 獲利了結 (嚴重高估區) 大幅減碼現股，確保泡沫利潤落袋。
2. 停止追價 (偏高警戒區) 降低部位水位，控制風險槓桿。
3. 試單佈局 (合理震盪區) 維持常態操作水位，進行區間操作。
4. 恐慌加碼 (便宜低估區) 動用預備金逢低買進，累積部位。
5. 危機入市 (極度超跌區) 股價逼近絕對防禦底線，極大化勝率部位。

🌍 左側大盤交易策略

操作大盤 ETF（0050）或權值股時切換，依均線動態調節：

🛡️ 穩健型 (以季線為核心)
  • • 極度過熱：大盤大幅偏離季線上揚 ➡️ 狂熱減倉，保留 10% 水位。
  • • 合理震盪：大盤在季線附近游走 ➡️ 常態試單，維持 45% 水位。
  • • 嚴重超跌：大盤跌破季線下修 ➡️ 便宜加碼，增至 85% 水位。
  • • 長空破底：跌破年線支撐 ➡️ 危機入市，動用預備金 100% 買進。
🔥 激進型 (以月線為防線)
  • • 強勢多頭：站上月線順勢做多 ➡️ 15% 試單，順勢加碼。
  • • 短線破位：跌破月線 ➡️ 分批防守，30% 少量避險。
  • • 中線回測：跌破季線 ➡️ 箱型分批建倉，70% 佈局。
  • • 超限跌幅：跌破年線或偏離過大 ➡️ 重倉買進，100% 滿手部位。
